# Cat in the Park

A 2D block-style browser game. Guide a cat through the park, jump over obstacles and ponds, collect fish, and reach the picnic.

Open `index.html` in a browser to play. No build step or dependencies are needed.

## Controls

- Left / Right arrows: walk
- Space or Up arrow: jump
- P or Escape: pause or resume
- R: restart

Touch controls appear on narrow screens.
